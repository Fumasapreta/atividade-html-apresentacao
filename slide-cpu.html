Unidade de Processamento

CPU - Central Processing Unit

O cérebro do computador

O que é a CPU?

A Unidade Central de Processamento (CPU) é o componente principal de um computador responsável por executar instruções e processar dados.

  • Executa operações aritméticas e lógicas
  • Controla o fluxo de dados entre componentes
  • Interpreta e executa instruções de programas
  • Coordena todas as atividades do sistema

Componentes Principais

🧮 ULA

Unidade Lógica e Aritmética

Realiza operações matemáticas e lógicas

🎛️ UC

Unidade de Controle

Coordena e controla as operações da CPU

💾 Registradores

Memória Interna

Armazena dados temporários de alta velocidade

⚡ Cache

Memória Cache

Memória rápida para dados frequentes

Ciclo de Instrução

A CPU executa instruções em um ciclo contínuo:

  • 1. FETCH - Busca a instrução na memória
  • 2. DECODE - Decodifica a instrução
  • 3. EXECUTE - Executa a operação
  • 4. STORE - Armazena o resultado

Este ciclo se repete bilhões de vezes por segundo!

Características de Performance

Clock Speed

Medido em GHz (Gigahertz)

Exemplo: 3.5 GHz = 3,5 bilhões de ciclos/segundo

Núcleos

Múltiplos processadores em um chip

Exemplo: Quad-core, Octa-core

Cache

L1, L2, L3

Quanto maior, melhor!

Threads

Execução paralela de tarefas

Multithreading

Principais Fabricantes

  • Intel - Core i3, i5, i7, i9 (Desktop e Laptop)
  • AMD - Ryzen 3, 5, 7, 9 (Desktop e Laptop)
  • Apple - M1, M2, M3 (Silicon)
  • ARM - Processadores para dispositivos móveis
  • Qualcomm - Snapdragon (Smartphones)

Conclusão

A CPU é o componente mais importante do computador, responsável por processar todas as informações e executar programas.

Sua velocidade, número de núcleos e arquitetura determinam o desempenho geral do sistema.
